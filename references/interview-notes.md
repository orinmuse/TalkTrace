# Interview Notes Workflow

## Purpose

把访谈转写或记录整理成可继续核实和用于后续访谈的结构化纪要，同时保留受访者原意、重要限定和来源边界。

TalkTrace 整理的是**访谈来源信息**，不是自动判定企业事实。

## 1. Accepted input

优先使用当前环境可直接读取的：

- 访谈转写文本；
- Markdown / TXT；
- Word-like readable text；
- 现场记录与转写组合材料。

原始音频转写不是 v0.1 必需能力。若宿主运行环境能可靠转写，可把转写结果作为输入；否则要求提供可读文本。

## 2. Preserve the source before summarizing

先识别受访者实际表达的：

- 核心观点；
- 事实性陈述；
- 具体案例；
- 判断/评价；
- 建议；
- 数字、时间、范围和例外；
- 明确“不知道 / 不确定 / 需要确认”的内容。

不得因为结构化输出而丢掉会改变意思的重要限定。

## 3. Default structure

```markdown
# 访谈纪要

## 1. 基本信息
- 受访者：
- 职务/角色：
- 时间：
- 主题：

## 2. 核心观点

## 3. 关键事实性陈述

## 4. 典型案例与例证

## 5. 问题与建议

## 6. 待核实事项
```

需要稳定版式时，可使用 `assets/interview-notes-template.md`。没有来源支持的字段留空或删除，不得为了填满模板补造信息。

## 4. Meaning of “factual statement”

“事实性陈述”仅表示：

> 受访者把该内容当作事实、流程、事件或数字进行描述。

它不表示该内容已经被其他资料、数据或独立来源验证。

必要时使用：

- `受访者称……`
- `据受访者介绍……`
- `该说法尚需结合制度/数据/其他访谈核实。`

不要在压缩纪要时删除这些来源限定。

## 5. Distinguish statement types when material

当区分会影响后续判断时，识别：

- **事实性陈述**：对流程、事件、数据、角色行为的描述；
- **观点/判断**：对原因、效果、优先级等的解释；
- **建议**：希望未来如何调整；
- **案例**：说明观点或事实的具体例子；
- **待核实项**：无法仅凭本次访谈确认的关键内容。

不需要给每一句话机械打标签。

## 6. Preserve source trace when available

如果原转写/记录已经包含时间戳、段落号、说话人标签、页码或其他稳定定位信息：

- 对重要数字、关键流程、典型案例、争议性表述和待核实事项，优先保留简短来源定位；
- 定位应足以帮助顾问回查，不要求给每一句话建立引用；
- 输入没有定位时，不生成虚假时间戳、段落号或页码；
- 不为了“可追溯”建设额外证据图谱、数据库或复杂编码体系。

## 7. Uncertainty and transcript defects

出现以下情况不得自行补全：

- 转写明显缺字或中断；
- 人名、数字、制度名称听写不清；
- 指代对象无法确定；
- 前后说法互相矛盾；
- 记录只保留片段，无法确认完整语境。

使用 `待核实`、`原记录不清`、`无法确认` 等明确标记。

## 8. Compare with current context when useful

如果当前上下文已经存在项目资料或前序访谈，纪要完成后可以识别少量重要关系：

- 本次补充了哪些此前未知信息；
- 与正式资料或前序访谈是否存在实质冲突；
- 哪些重要说法仍只有单一来源；
- 哪些开放问题得到部分回答。

详细的“新增信息 → 后续访谈刷新”按 `references/interview-delta.md` 执行。

如果此前资料不在当前上下文，不假装能够做历史对比。

## 9. Follow-up suggestions

只有出现明确的信息缺口、冲突或单一来源高价值说法时，才增加后续建议，例如：

- 查哪类制度/数据；
- 向哪类角色继续确认；
- 下一场访谈应验证什么。

不要自动扩展成正式诊断或大段行动计划。

## 10. Quality check

- 有没有遗漏会改变理解的重要观点、数字或案例；
- 有没有把受访者观点写成客观事实；
- 有没有增加原文不存在的原因、动机或评价；
- 重要限定词是否被压缩掉；
- 原材料已有的重要来源定位是否被无必要丢掉；
- 不确定内容是否明确标记；
- 与当前上下文比较时是否保持来源边界；
- 纪要是否足够简洁，能够被后续顾问直接继续使用；
- 是否越界形成企业级正式诊断。
