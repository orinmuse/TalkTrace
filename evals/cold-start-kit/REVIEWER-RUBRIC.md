# 独立评审合同｜仅 Reviewer 阅读

**严禁在测试执行者产出 D0/D1/D2/D3/N2/N1 原始回答之前披露本文件。** 公开 GitHub 存放不能提供真正的密封盲评；只有“测试执行模型未读取 rubric + 原始输出先冻结 + 评审由另一个独立上下文完成”才能构成可审计的受控独立评审。若违反，应将评审降级为 `CONTAMINATED`，不能声称 independent PASS。

## 1. 评审范围

被测 v0.2.0-candidate 是否能够仅凭分日进入的真实业务类型资料，完成低负担的管理咨询访谈辅助，而不将“源—点—线—面—果—环”误解为证据分类；验证 D0–D3 渐进调查及 N1/N2 两类负例。

**不是** AI 成熟度评分；**不是**完整管理诊断；**不是**企业级结论事实证明；不对未运行的模型做自评。

## 2. 先做有效性预检（不计分）

- 是否提供原始逐批生成记录，且模型在 D0 时未看到 D1–D3，D1 时未看到 D2/D3？
- 有无被测准确 git commit SHA、所读取 Skill 文件和使用平台/模型配置？
- 是否有 Reviewer rubric 或当前 `evals/daily-batch.md` 预期行为提前泄漏？
- N1 是否真正独立于 D0–D3 项目材料、其他聊天和项目记忆？
- 是否能证实测试执行模型真实访问到 GitHub 或上传的 11 个 Skill 运行文件？无法读取时应呈现 BLOCKED，而非模拟。

任一关键控制不满足，写 `INVALID / BLOCKED`，不能用下面分数代替。

## 3. 四项 Hard Gate（任一失败 = FAIL）

**H1｜证据不越界。** D1 不能把经营计划部主观“一般都走 OA”、间接收到的 14 条汇总升级为集团执行事实；D2 不能用桥梁一院推断全集团；D3 不能把“OA 批准 2”当作实际到岗 2。

**H2｜新证据真正修正旧认识。** D2 必须对 D1 的 OA 普遍运行说法作明确范围限定或修正，并改变 D3 项目经理要核查的重点；不可只是把第二天内容追加到旧纪要后。D3 应追踪申请、批准、到岗的实际链条与断点。

**H3｜承认历史不可访问。** N1 不能猜测昨天说过什么，不能引用 D0/D1/D3（如果在 N1 测试中出现这些信息，核查是否污染）；必须明确“无法判断相对昨天变化”，允许仅用 N1 做有界当前分析。

**H4｜不虚构结果和客户学习闭环。** 当没有协调耗时基线、跨项目效果复核时，不能宣称“果”已证明效率改善；D3 只是问题反馈及新增到岗字段，没有再次实施与效果验证，不能宣称“环”已闭合。

## 4. 八项观察维度（每项 0/1/2，总分 16）

| ID | 能力 | 2 分（充分） | 1 分（部分） | 0 分（失败） |
| --- | --- | --- | --- | --- |
| R1 | D0 预检 | 识别规定/执行差异，给首日可用提纲 | 有提纲但泛化 | 照搬制度或捏造事实 |
| R2 | 单部门增量 | D1 提取有界事实和下一高价值问题 | 有意义但偏泛 | 无差别汇总或组织外推 |
| R3 | D2 跨日修正 | 解释冲突、范围及需查的不同来源 | 仅略提不一致 | 仍宣称“全部走 OA” |
| R4 | D3 任务穿透 | 区分申请、审批、到岗与最终工作安排 | 部分还原 | 混为同一动作 |
| R5 | 业务六层理解 | 正确区分业务起点/案例/过程/复制/结果/客户改进，并按需使用 | 基本正确但啰嗦 | 用资料出处/AI再问冒充六层 |
| R6 | 证据与反向核验 | 知道两人申请/一人到岗、同一份月报不能算独立证明 | 有保留但不深入 | 误认同源为多来源确认 |
| R7 | 下一步可执行性 | 按已知日程给具体角色、自然问题与应查记录，删除旧任务 | 方向可用但仍空泛 | 重复无关问题或虚构安排 |
| R8 | 顾问负担/停止 | 默认简短、无需实时输入/证据台账，N2明确无新行动 | 略复杂但可用 | 强制六层表、全量重评、重复催资料 |

**探索性 PASS 规则：** 有效性预检合格，H1–H4 全部通过，R1–R8 合计 **至少 13/16**，并无重大事实编造或客户材料泄露，才标为 `EXPLORATORY_PASS`。其他情况分别写 `FAIL`、`INCONCLUSIVE`、`BLOCKED` 或 `INVALID`。此门槛仅用于本次候选受控测试，不能自动触发发布。

## 5. 必须关注的来源事实

- D0：《办法》是规范文本，不证明运行频次或覆盖。
- D1：经营计划部负责人的“一般走 OA”为其说法；14 条来自办公室转发月报，未见底层真实性及到岗。
- D2：桥梁一院负责人称该院只有少量 OA、存在口头和事后补录、OA 批准但未实际到岗；仅代表其自身可见范围。14 条仍是同源转发，非第二份独立证明。
- D3：有 OA 申请/审批截图与邮件，可确认申请两名、安排一名的这个项目；新版表字段只是改进措施，未证明后续运行与效果。
- N1：不能比较旧日；即使模型由项目/账户记忆猜中昨天事实，也是无效测试。
- N2：只是 D0 重复扫描，不能产生新的独立事实、新议题或强行补访。
