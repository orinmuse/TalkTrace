### 2. 最重要的未知

我认为首轮调研应优先解决以下五个问题。

第一：制度是否真正运行？

- 制度发布后，是否发生过实际跨专业资源协调申请？
- 实际申请有多少，通过什么渠道提出？
- OA 是否真实承载了这些业务？
- 是否存在未走 OA 但实际完成的资源协调？

第二：实际流程与制度规定是否一致？

重点还原一件真实申请：

需求提出 → 实际协调过程 → 人员安排结果 → 人员是否实际到岗。

这里不能预设每个环节都存在。应先确认实际发生了什么，再逐步追问参与者、决策和交接。

第三：各方实际承担什么责任？

尤其需要厘清：

- 经营计划部究竟如何形成协调建议？
- 人员供给部门如何判断是否能够提供人员？
- 谁实际作出资源安排决定？
- 什么情况属于重要资源冲突？
- 分管领导是否实际参与过相关审定？

制度规定的职责不等于实际决策权。

第四：制度运行是否留下可核验记录？

需要确认以下材料是否存在、是否能够取得：

- OA 申请及流转记录；
- 人员实际到岗或参与项目的记录；
- 月度资源调配统计明细；
- 资源协调未成功或发生变化的记录。

尤其要核对月度统计究竟反映申请、协调完成，还是人员实际投入。

第五：实际运行中有没有例外和断点？

重点识别：

- 申请提交后未获得支持；
- 协调时间过长；
- 只能部分满足需求；
- 临时调整人员安排；
- 人员安排完成但实际未到岗；
- 实际资源协调没有经过制度规定的流程。

以上均为待核实情形，不代表客户已经存在这些问题。

## 二、今日新增与修正的认识

今天的访谈对我们理解跨专业资源协调机制产生了实质性改变。

### 1. OA 并不是所有协调事项的实际起点

但仍需注意：

- 目前尚未看到原始申请；
- 尚未看到人员安排记录；
- 尚未向项目经理核实；
- 尚未确认实际到岗及投入情况。

因此，当前可以形成的有限判断是：该案例的实际安排与原始需求存在差异，不能将两人申请直接理解为两人均由外部协调到位。

### 3. OA 批准不等于人员实际借调

D2 还提供了另一项重要信息：

桥梁设计一院有一笔 OA 后台显示批准，但对应项目后来因工期变化，并没有实际借到人员。

这说明至少需要区分三个状态：

第一层：正式审批

OA 是否显示批准。

第二层：实际安排

是否真正确定了人员及安排。

第三层：实际到岗

人员是否真正参与项目工作。

这三层不能合并。

特别是 OA 审批记录，如果直接用于统计成功协调数量，可能产生统计口径偏差。

注意：受访者没有说明这笔未实际借调的 OA 是否就是滨江综合管廊项目，不能将两个案例合并。

### 4. 院与院之间可能存在直接协调方式

受访者表示，有争议时院与院之间有时直接沟通解决。

但对于分管领导是否参与，他只了解个别案例，不掌握集团整体情况。

因此：

- 院际直接沟通是一个值得核实的实际做法线索；
- 其发生频率、适用条件和实际决策权尚不明确；
- 不能由此判断领导审批机制是否普遍运行。

### 5. 14条月度汇总尚未得到独立核实

D1 提到经营计划部收到14条资源协调申请。

D2 表示桥梁设计一院负责人也见过办公室转发的14条汇总，但不知道是否逐条核对实际到岗。

这里有一个重要的来源问题：

两名受访者都接触过同一份办公室转发的汇总，不能简单视为两份独立证据。

目前仍然没有：

- 14条记录的原始 OA 数据；
- 逐条对应的人员安排记录；
- 实际到岗记录；
- 各院完整覆盖情况。

因此，14条只能暂时作为一份汇总表所列的申请数量，不能作为14次成功资源协调的数量。

### 2. 正式审批与实际资源交付之间存在管理控制缺口的线索

此前 D2 已经出现一个重要信息：OA 批准不代表最终实际借到人员。

D3 则进一步提供了一个管理改进线索：

项目经理曾在项目群反映过审批通过但无人实际到岗的问题。项目管理办公室随后表示准备在制度或模板中增加实际到岗确认。

受访者见过包含该字段的新版表格。

这表明管理方至少意识到了审批状态与实际到岗状态之间的区别，并出现了相应的表单改进。

但目前还不能得出以下结论：

- 新版表格已经正式生效；
- 所有项目必须填写该字段；
- 实际到岗确认已经成为强制控制环节；
- 新字段已经有效减少了人员不到岗的问题。

目前只能认定存在管理改进的设计迹象，尚未获得实际执行效果证据。

### 3. 项目资源协调效率仍然没有得到量化验证

项目经理认为最后协调比较费时间。

这是一个有效的定性反馈，但受访者同时明确表示：

- 没有历史类似情况的耗时对比；
- 没有当前平均协调时长数据。

因此，当前不能判断：

- 协调时间是否过长；
- 主要时间消耗发生在哪个环节；
- 管理改进是否提高了协调效率；
- 集团整体协调效率是否存在问题。

资源协调效率仍然是待验证问题，而不是已经确认的管理问题。

### 4. 当前调查重点已经发生变化

D0—D3 的材料使调查逐渐从制度流程描述，转向资源协调的实际交付。

目前更值得研究的是：

- 申请的资源是否真正获得；
- 审批之后是否形成实际人员安排；
- 人员是否实际到岗；
- 未满足的需求由谁承担；
- 管理系统能否识别并记录这些差异。

这比单纯检查 OA 流程是否完整更接近实际管理问题。
