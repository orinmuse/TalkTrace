# D0｜进场前资料与访谈安排

以下企业及资料均为合成测试材料。

## 项目目标

客户希望了解集团当前薪酬与绩效管理体系的实际情况，为后续是否优化提供基础认识。本轮任务是**现状摸底**，暂不要求正式问题诊断、根因分析或制度方案设计。

初步调查范围：集团总部及三个设计院。员工类别是否全部采用同一套规则尚未明确，项目组也不清楚是否存在特殊岗位或项目人员分类。

## 已有资料

### 资料 A｜《薪酬管理办法（2024年修订）》摘要

- 文件规定岗位对应若干职级档位。
- 文件提到薪酬标准参考职级区间确定。
- 文件出现“绩效相关收入”表述，但没有完整列明收入构成、适用人员、计算口径及实际分配办法。
- 当前没有提供个人薪酬样本、工资总额数据或实际分配记录。

### 资料 B｜《绩效考核管理办法》摘要

- 文件提到部门和员工年度考核。
- 文件没有完整说明指标如何形成、考核如何评分、结果如何复核或反馈。
- 文件没有明确说明绩效结果如何影响个人薪酬。
- 当前没有提供考核表、评分数据或实际结果应用样本。

## 初步访谈安排

- D1：人力资源部负责人；
- D2：财务负责人；
- D3：某设计院负责人；
- D4：员工代表。

暂时没有更多组织职责、具体时间和访谈时长约束。

## 本轮任务

请完成进场前资料预检，形成：
1. 当前调查对象和范围的初步理解，指出关键范围未知；
2. 一份与项目目标相匹配的轻量现状主题地图；
3. 对四类受访对象分配不同的信息任务；
4. D1 人力资源部负责人的首场访谈提纲，建议时长可合理建议；
5. 明确哪些信息目前只能确认制度写了什么，哪些实际运行情况仍未知。

请以咨询顾问可直接使用的方式输出。不要把行业常见薪酬做法当成客户现状。
