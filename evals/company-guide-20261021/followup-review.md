# 任务2、3定向复核

本次仅阅读 followup-task.md 与 followup-output.md，属于定向后续复核，不是重新开展的盲态基线比较，不据此推断与其他稿件的版本关系。

**结论：两项任务均可作为受控使用的问题清单，未发现必须返修的实质性失败。** 骨干访谈须按交流说明，在开始前明确个人信息采集、信息使用及保密安排。现有题数可执行，但30分钟7题和20分钟5题的追问余量较小，建议主持人控制开场和个案展开时间。以下将已满足要求与可选改进分开说明。

## 关键检查

| 维度 | 观察及判断 |
| --- | --- |
| 岗位、薪酬、绩效的存在性 | 任务2第3题先问“是否有明确的岗位设置及职责要求”，第5题先问“是否开展绩效评价”，第6题先问“是否有明确的薪酬分配规则”，再以“如有”展开。没有把未调查的安排认定为存在或失效。 |
| 对现状的中性探询 | 任务2第2题问实际职责与协作，且仅在“如有需要优化的环节”时要求举例；第4题同时问能力“保持或加强”，允许正面与改善两类回答。第1题“最应解决哪些问题”符合已确定的优化项目目的，不等于已断言具体问题存在。 |
| 骨干研究的条件状态 | 任务3交流说明准确写明“仅在讨论是否研究”“尚未批准股权方案”“未明确参与资格”，并明确不预设参与资格或意愿。第3题仍问是否必要开展研究，第4、5题均以“若开展相关研究”开头，没有把研究或股权方案写成既定项目。 |
| 激励现状的存在性 | 任务3第2题先问“是否有您了解或经历过的认可、激励做法”，分别处理“如有”“如无”，不预设员工已经获得某种激励。 |
| 信息使用及保密 | 交流说明明示“尚待确认，交流开始前需先明确”，没有虚构匿名、保密或用途限制承诺。该表述清楚建立了开始访谈前的条件，但本文件本身并不能证明实际安排已经完成确认。 |
| 自愿回答及敏感信息 | 交流说明允许跳过不便回答的问题、回答“不清楚”或“暂不判断”，第3题再次允许暂不判断；不涉及出资金额、持股比例。其余问题只要求工作体验和一般意见，未索取财务、持股意愿或资格证明。 |
| 任务相关性与文稿形式 | 任务2覆盖组织协作、岗位、队伍、绩效、薪酬及优化边界，没有附邀请函；任务3聚焦工作体验、研究必要性、可比较的方式及公平和选择。中文、称谓、编号和结束语适合公司材料；“任务2”“任务3”作为交付分隔标签可在发送时去除。 |

## 时间可行性

任务2为30分钟7题。若开场、收尾合计约3分钟，平均每题约4分钟。第1、3、5题可以简答；第2题的实例、第6题的规则与原则比较、第7题的优先级、约束和成效标准需要主持人分配时间。总体可以完成概括性领导访谈，但不宜期待对岗位、薪酬和绩效各自作详细机制诊断。用户没有要求在单场访谈中完成该类诊断，因此这不是任务失败。

任务3为20分钟5题。扣除交流说明确认及收尾，通常每题约3分钟；第1题工作背景与诉求、第2题单一实例、第3题了解程度与必要性、第4题研究内容、第5题公平及顾虑，逻辑清晰。若受访者实例较长，第4、5题容易出现重叠展开。可以通过先让其指出最重要的一项、再按剩余时间追问来执行，无须当然判定超时。

## 可选改进，不属于实际失败

1. **薪酬题可先事实、后评价。** 任务2第6题当前由“是否有规则”直接转入“应体现哪些原则”及一致性评价。若希望获得更可核验的现状信息，可先问规则的主要依据及实际运行，再问原则和评价。现稿仍允许回答运行情况，并未编造现状。
2. **压缩重复的研究优先事项。** 任务3第4题的“激励方式或规则”与第5题的“公平性、适用范围或个人选择”有部分交集。第5题可作为第4题的必要追问及补充，增加20分钟内的余量。保留5题也可执行。
3. **敏感边界可以更直白。** 可补一句“无需提供个人收入、资产或评价具名同事”，但现稿没有索取这些信息，且已设访谈前确认及跳答机制，因此不能将未补此句认定为隐私失败。
4. **对外文件可移除任务标签。** 将“任务2”“任务3”从标题移出，使其更像独立发送的公司文件。这是版面润色，不影响问题内容合规性。

受控使用的核心前提是履行稿件已经写明的访谈前确认；在此条件下，无需因为本次复核而另行重写两份清单。
