# 澄岳工程咨询公司访谈材料

说明：所提供运行文件未含天强公司专用版式样稿，以下按正式客户发送稿结构编排。

## 一、下一阶段发展规划项目

### 访谈邀请函（共用）

尊敬的各位领导、同事：

为做好澄岳工程咨询公司下一阶段发展规划研究，受公司委托，澄岳项目组拟开展访谈，了解公司发展目标、市政设计与检测业务情况，以及其他方向的探索考虑，听取有关发展重点与实施条件的意见建议。

本次访谈对象为公司领导、综合管理部负责人、设计业务负责人，每场预计45分钟，具体时间、地点另行协调。各角色访谈提纲附后，供提前了解交流内容。

访谈信息的使用范围及保密安排将在访谈前另行沟通确认。感谢您对项目工作的支持！

澄岳项目组  
2026年10月21日

### （一）公司领导访谈提纲

访谈时长：45分钟，含交流与补充时间。

**发展目标与业务选择**

1. 对公司下一阶段发展，您最希望实现哪些目标？判断规划成效时，应重点关注哪些结果？
2. 您如何评价现有市政设计与检测业务的发展情况？哪些方面值得延续，哪些方面需要进一步研究？请结合具体情况说明。
3. 公司目前探索过或正在关注哪些其他方向？如有，分别出于什么考虑，已掌握哪些信息，还需验证什么？

**发展条件与实施重点**

4. 如果需要在现有业务发展与其他方向探索之间安排资源，您认为应遵循哪些判断标准？有哪些需要重点权衡的事项？
5. 从发展目标出发，公司现有组织、人才及支撑能力能提供哪些支持？是否有需要补充或调整的方面，应如何确定先后顺序？
6. 您认为规划研究首先应澄清哪些关键问题？对实施节奏、投入边界及风险承受范围，有哪些原则或建议？

### （二）综合管理部负责人访谈提纲

访谈时长：45分钟，含交流与补充时间。

**职责与运行情况**

1. 请介绍综合管理部当前实际承担的工作，以及与公司发展规划相关的信息和资料掌握情况。
2. 请以近期一项涉及业务部门的实际工作为例，介绍需求提出到工作完成的实际经过；哪些做法在其他事项中也会采用，哪些因情况而异？
3. 从您掌握的信息看，现有人员、制度及管理工具对市政设计与检测业务提供了哪些支持？是否存在需要进一步了解的需求，请举例说明。

**规划支持与实施条件**

4. 对公司正在探索的其他方向，您了解哪些情况？如已开展相关支持工作，请介绍实际内容；如尚未开展，您认为需要先明确哪些条件？
5. 面向下一阶段发展，您认为现有管理与支撑方式有哪些值得保留的做法，是否有需要调整或新增的内容？依据是什么？
6. 为支撑规划研究与实施，哪些资料可以提供，哪些信息还需补充核实？如后续需要落实相关工作，您对协作安排和推进节奏有何建议？

### （三）设计业务负责人访谈提纲

访谈时长：45分钟，含交流与补充时间。

**业务与项目运行**

1. 请结合您了解的市政设计项目，介绍当前客户需求和业务获取情况；近期是否出现值得关注的变化？如有，请举例说明。
2. 请以近期一个实际设计项目为例，介绍从承接到交付的主要经过，以及实际涉及的人员和资源安排；这一案例与其他项目有哪些相同或不同之处？
3. 从实际项目看，设计业务有哪些得到客户认可的能力？是否存在影响项目承接、交付或收益的因素，具体表现是什么？

**协作与发展建议**

4. 在您了解的项目中，设计业务与检测业务或其他部门是否发生过协作？如有，请介绍具体案例及效果；如没有，您认为是否有协作需求？
5. 面向下一阶段，现有设计业务有哪些值得进一步研究的发展空间？对于公司探索的其他方向，您认为有哪些可利用的能力、需要验证的需求或进入条件？
6. 如推进您建议的发展事项，优先需要哪些人才、资源或管理支持？您建议先开展什么行动，并通过什么结果判断是否继续推进？

## 二、组织与人力资源优化项目——院领导访谈问题清单

访谈时长：30分钟，含交流与补充时间。

**优化目标与现状了解**

1. 您希望本次组织与人力资源优化重点研究哪些事项？最终应在哪些方面体现成效？
2. 从您掌握的情况看，公司目前组织分工与岗位安排是怎样的？请结合一项近期工作，介绍实际职责和协作情况，以及您认为值得保留或进一步了解的方面。
3. 公司目前是否有明确的薪酬分配规则？如有，您如何理解其主要依据和执行情况；如尚不明确，您希望重点了解哪些情况？
4. 公司目前是否开展绩效评价或考核？如有，主要关注什么，结果如何使用；如尚未开展，您认为是否有建立相关安排的需要？

**原则与推进安排**

5. 对组织、岗位、薪酬和绩效可能涉及的调整，您认为应遵循哪些原则？有哪些需要重点权衡的事项，建议按什么节奏研究和推进？

## 三、骨干激励研究讨论——骨干员工访谈问题清单

访谈时长：20分钟，含交流与补充时间。

本次交流用于了解工作体验及对激励方式的意见，供讨论是否开展骨干激励研究参考；目前未形成具体方案或参与资格安排。个人信息采集及访谈信息使用、保密安排将在访谈前另行沟通确认。回答无需提供个人收入、资产等信息，也无需评价具名同事。

**工作体验与激励需求**

1. 请以近期一项工作为例，介绍您承担的主要任务，以及其中让您感到有动力或影响投入的因素。
2. 在您了解的范围内，公司是否有对员工贡献予以认可或激励的做法？如有，哪些对您有实际帮助，是否有需要进一步了解或改进之处？
3. 从个人工作体验看，哪些支持或激励最有助于您持续投入并发挥作用？例如成长机会、工作授权、认可或报酬，您最看重什么，为什么？

**研究建议**

4. 如果公司进一步研究骨干激励，您最希望先澄清哪些问题？对公平性、贡献认定及意见沟通，有哪些建议？

## 四、社区志愿服务负责人访谈问题清单

访谈时长：20分钟，含交流与补充时间。

**服务排班**

1. 请以最近一次志愿服务为例，介绍服务任务和参加人员是怎样确定的，以及当天实际如何安排工作。
2. 这次服务是否出现过临时缺人、换班或任务变化？如有，当时如何处理；如没有，遇到这类情况是否已有约定？这些安排在其他活动中是否也适用？

**沟通与协作**

3. 在这次服务中，志愿者与社区工作人员或其他参与方实际如何配合？是否有需要交接或共同处理的事项，请举例说明。
4. 从您的经验看，目前排班和协作中有哪些做法值得保留，是否有需要改善之处？如果先改进一件事，您会选择什么，需要哪些支持？
