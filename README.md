# TalkTrace

TalkTrace 是一个面向咨询顾问的轻量调研访谈 Skill，帮助把已有项目资料转化为三类可直接继续工作的成果：

1. **访谈计划**：识别建议访谈对象、分类并形成初步排程；
2. **访谈提纲**：结合项目目标、已有资料与受访者角色生成差异化问题；
3. **访谈纪要**：把访谈转写整理成结构化、可追溯、可继续验证的信息。

TalkTrace 的目标不是替代顾问判断，而是减少重复阅读、整理和基础编写，让顾问把更多时间用于判断、追问和验证。

## 使用方式

将已有项目资料提供给支持 Skill 的 AI 运行环境，然后直接用自然语言提出任务，例如：

- `根据这些项目资料帮我制定访谈计划。`
- `给人力资源负责人准备一份访谈提纲。`
- `把这份访谈转写整理成专业纪要。`

正常用户不需要理解内部 Workflow、Schema 或状态机制。

## v0.1 能力边界

TalkTrace v0.1 只覆盖调研访谈中的三个高频任务，不负责：

- 把单次访谈直接升级为企业事实或正式管理诊断；
- 自动录音或依赖第三方转写服务；
- 自动发送邮件、预约会议；
- RAG、向量数据库或长期项目状态；
- 自主 Agent、项目管理系统或诊断报告生成。

需要正式管理诊断时，应由顾问或下游诊断能力基于更完整的资料、数据与交叉验证继续处理。

## 设计原则

- **项目资料优先**：客户真实资料优先于通用行业常识；
- **角色差异**：不同受访者必须体现不同的信息任务，而不是替换职位名称；
- **中性求证**：把假设变成开放、可验证的问题，不把预设结论写进问题；
- **来源纪律**：受访者陈述首先是来源，不自动等于已验证事实；
- **最少追问**：只询问会实质改变当前成果的信息；
- **复杂度内收**：用户只需提供材料并提出自然语言任务。

## 数据与隐私

本仓库计划公开，因此仓库历史从第一天起按公开标准管理：

- 不提交真实客户资料；
- 不提交真实访谈记录、姓名、敏感数字或专有制度文本；
- 示例与测试材料必须为合成或经独立审查的公开安全材料；
- TalkTrace v0.1 不要求外部 API、账号凭证或遥测。
