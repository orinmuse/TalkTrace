# TalkTrace v0.1.1

日期：2026年10月21日。

## 发布决定

Owner 明确指定本轮版本为 v0.1.1，并授权封装 WorkBuddy 可安装压缩包及向指定同事邮件交付。此决定替代 PR #9 此前的 prospective v0.2.0 命名和等待分发安排；工程变化范围仍按原 Standard Change 管理，不因版本号改为 patch 而降低验证要求。

Skill Manager 决定按已知限制发布 v0.1.1 同事试用分发包。WorkBuddy 本版安装加载与真实项目现场复核继续为 NOT TESTED，属于公开保留的现场验证项，不伪记为通过。原 v0.1.0 标签和发布记录不修改；本次不提升为 stable，也不声称全场景效果优于旧版。

## 本版变化

- 按需启用公司访谈文档结构，包含邀请函、角色化主题、补充意见及致谢。
- 按战略、组织人力、治理激励项目选择问题，避免将历史客户事实带入当前项目。
- 明确领导、职能、生产科研及骨干员工的信息任务差异。
- 修正机制存在性、拟议研究状态与信息使用说明的应用规则。
- 新增两个运行文件；安装包仅包含11文件完整运行目录。

原有通用提纲、访谈计划、纪要、后续访谈刷新和无状态恢复方式保持；不加入数据库、持久项目记忆、转写服务或自动发送功能。

## 验证与限制

前序候选结构与打包检查、云端隔离试用、独立匿名对照审查及失败修正后的定向复核，见 `evals/company-guide-20261021/acceptance.md` 及同目录原始输出。首轮评审没有证明新版整体优于旧版；修正后的两个受影响任务可受控使用。

版本与文档同步后再次执行 frontmatter 验证、两套现有工作流检查、干净打包和 ZIP 解压逐字节核验。WorkBuddy 实际安装加载、文件生成能力和现场时长，以目标环境验证为准。未确认保密安排的邀请函仍为待补草稿；正式客户发送前由顾问核对。

## 升级使用

导入 `TalkTrace-v0.1.1-WorkBuddy.zip`；目录导入方式选择解压后的 TalkTrace 文件夹，确保 SKILL.md、references 和 assets 同级。备份旧技能后升级，避免混装。技能不要求额外 API、数据库或账号凭证。

可用请求：“根据这些资料准备45分钟公司领导访谈提纲，按天强公司格式。”公司格式只有明确要求或沿用已提供公司模板时启用。
